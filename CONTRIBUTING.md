# Contributing to Promptfolio

Thanks for helping improve the catalog. You can suggest a prompt through the **Prompt submission** GitHub issue template, or submit a pull request.

## Prompt guidelines

- Submit an original, useful image-generation prompt that has been tested in the named model.
- Use a concise title and one of the existing categories: `Portrait`, `Product`, `Illustration`, `3D`, `Travel`, or `Design`.
- Write complete instructions, including the intended subject, composition, lighting, material, or style where useful.
- Do not submit harmful, deceptive, copyrighted, private, or personal-data-focused content.
- Avoid prompts that imitate living artists. Describe visual qualities instead.

## Pull requests

1. Add the prompt to the appropriate model in `prompts-data.js`.
2. Include `title`, `tag`, `category`, and `text`. `badge` is optional and should be used sparingly for `New` or `Popular` entries.
3. Keep the prompt wording clear and check that the site still loads in a browser.
4. In the pull request description, say which model you tested and what the prompt is intended to create.

By contributing, you agree that your submission may be published under this repository's license.
